### About

I mostly work with **C/C++**, embedded systems, firmware and low-level software. I also enjoy electronics, PCB design and exploring the space between hardware and software.

Some of my projects take me into backend development, databases, real-time communication and Linux infrastructure, too.

My experience also includes **Assembly, kernel development, microcontrollers, RTOS, hardware and firmware modding, reverse engineering, native applications and game console development**.

I develop full-stack applications, enterprise management systems, Android device management solutions (MDM), Windows desktop applications and real-time distributed services.

I work with network programming, custom communication protocols, REST APIs, WebSocket, SignalR, TCP/IP, UDP, TLS/SSL, relational databases and application security.

I'm also the founder of **[The Archlevel Foundation](https://github.com/thearchlevel)**, an open-source initiative focused on low-level development, embedded systems, developer tools and experimental software projects.

### Currently building
