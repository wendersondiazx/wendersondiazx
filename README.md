### About

I mostly work with **C/C++**, embedded systems, firmware and low-level software. I also enjoy electronics, PCB design and exploring the space between hardware and software.

Some of my projects take me into backend development, databases, real-time communication and Linux infrastructure, too.

I'm also the founder of **[The Archlevel Foundation](https://github.com/thearchlevel)**, an open-source initiative focused on low-level development, embedded systems, developer tools and experimental software projects.
